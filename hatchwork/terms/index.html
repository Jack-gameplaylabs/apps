About the game

Nonograms are a traditional type of picture logic puzzle, and the word is used to describe how the game is played. Each puzzle in Hatchwork is checked to have a single solution that can be reached by logic, but the game is provided for entertainment and we do not guarantee any particular result, difficulty, or solving time. Daily puzzles are built into the game and become available by your device’s date.
